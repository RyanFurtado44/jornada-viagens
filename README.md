# Projeto Front-End: Responsividade e Organização

Este projeto foi desenvolvido durante o curso **HTML e CSS: Responsividade em layouts** da Alura. O objetivo principal foi aplicar técnicas avançadas de estilização e adaptação de layouts para criar uma experiência de usuário consistente em qualquer dispositivo.

---

## 🎯 Objetivos do Projeto

Desenvolver uma interface moderna, focada em boas práticas de arquitetura CSS, organização de arquivos e, principalmente, adaptabilidade (Mobile-First e Desktop).

## 🛠️ Tecnologias e Conceitos Aprendidos

### 📱 Responsividade de Ponta a Ponta
* **Criação de páginas responsivas:** Design adaptado para diferentes tamanhos de tela (Mobile, Tablet e Desktop).
* **Media Queries:** Aplicação de ajustes específicos para garantir a consistência visual em diversos breakpoints.

### 🎨 Arquitetura e Estilização CSS
* **Reutilização de Componentes:** Estruturação de estilos globais para reaproveitamento em múltiplas páginas, mantendo a identidade visual.
* **Classes Específicas:** Criação de classes para elementos únicos, evitando repetição de código desnecessária.
* **Hierarquia Visual:** Uso de marcações visuais estratégicas para destacar as informações mais importantes da página.

### 🧭 Navegação e UX
* **Indicação de Página Atual:** Implementação de feedbacks visuais no menu de navegação para orientar o usuário.
* **Organização Temática:** Diretórios de imagens organizados por temas, facilitando a escalabilidade e manutenção do projeto.

### 🚀 Deploy e Versionamento
* **Git & GitHub:** Uso do Git para controle de versão e integração contínua.
* **GitHub Pages:** Publicação oficial do projeto para acesso via navegador.
